# Data Directory Documentation

This directory houses static datasets or seeds generally employed heavily either natively on the application side or strictly used inside database populations.

## Files
- **`dine_ontario_with_tags.csv`**: A raw comma-separated tracking sheet containing vast arrays of localized entities representing the foundational data model for restaurants. In its raw form, data like specific cuisines (e.g., sushi, burgers), tags (e.g., good, cheap), and general geographic scopes are structured here, and ideally pushed upward to the system's external architecture or mapped manually into testing tools.
