# 🍽️ BiteMap

**Team:** Dev Patel · Mahdi Ali · Muhammad Mir · Rishi Jain · Devansh Shah

**BiteMap** is a social restaurant discovery platform where users can search for restaurants, track their dining history, connect with friends, and earn achievements — all in one place.

---

## 🚀 Quick Start

> **Prerequisite:** [Node.js](https://nodejs.org/) must be installed.

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev
```

Then open **http://localhost:5173** in your browser.

> **Windows users** (no terminal): double-click **`run.bat`** — it handles install + launch automatically.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | HTML, CSS, Vanilla JavaScript |
| Build Tool | [Vite](https://vitejs.dev/) |
| Backend / DB | [Supabase](https://supabase.com/) (PostgreSQL + Auth + Realtime API) |

---

## Features

| Category | Features |
|----------|----------|
| **Search & Discovery** | Search restaurants by name or cuisine tag; view ratings, address, and website |
| **User Profiles** | Register/login, set up a personal profile, view dining history |
| **Social** | Follow friends, search other profiles, see friend activity |
| **Ratings & Tracking** | Rate & review restaurants; tag as *Want to go*, *Visited*, or *Would go again* |
| **Dashboard** | Personal hub for all saved restaurants and recent activity |
| **Gamification** | Level up through app activity; earn cuisine-specific badges (e.g., *Sushi Scout*, *Super Eater*) |
